Functions in java:--

--> In java we have functions and methods. Functions can be defined anywhere (in or out of the class) but methods are a type of 
    functions that are only defined inside a class.

--> In functions we have two imp things, (i) actual values/ Arguments and (ii)formal values/ Parameters. The value which is passed
    from the function is called arguments and the place where it goes is called parameters.

--> In java the functions are always be called inside the main functions as all the codes start executing from the main function

--> In java the functions are stored in form of call stack, means first the main function then in form of stack the other function 
    will get stored in stack approach and so on. Once the function is completly executed it remove from the stack.

--> In functions the value passing is of two types (i) call by value and (ii) call by reference. 
    call by value :- here we pass the copy of the arguments, so any changes perfrom on it inside the functions is not showed up in
                     original functions.
    
    call by reference :- Here we pass the address of the variable and hence we are able to change the original function value inside
                         from the functions.

--> JAVA ALWAYS FOLOWS THE CALL BY VALUE APPROACH
